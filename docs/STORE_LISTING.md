# Store listing draft

## App name
SCRAP//YARD

## Short description
Buy broken tech. Repair it. Test it. Flip it for profit.

## Full description
Build a repair-and-resale empire from a tiny neon workshop.

Hunt the market for damaged phones, consoles, laptops, power tools and mystery electronics. Diagnose hidden faults, nail precision repairs, test your work, then sell each item for profit.

Every successful flip earns cash and reputation. Upgrade your workbench, improve diagnostics, unlock better parts and gain access to rarer stock as your workshop grows.

Prototype features:
- Offline single-player gameplay
- Buy → diagnose → repair → test → sell loop
- Timing-based repair minigame
- Item condition and fault system
- Cash, profit, XP and level progression
- Workshop upgrades
- Local save data
- No account required

Repair. Flip. Profit.
