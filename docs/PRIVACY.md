# SCRAP//YARD Privacy Notice — Prototype v0.2

SCRAP//YARD v0.2 is designed to operate offline.

The prototype does not request Android network access and does not include advertising, analytics, account, cloud-storage, location, contacts, camera, microphone, or payment SDKs.

Game progress is stored locally on the device using the Android WebView's local storage. Resetting app storage or uninstalling the app may remove this progress.

Because this prototype has no network permission, it does not transmit gameplay data to the developer.

Future versions that add ads, analytics, cloud saves, purchases, crash reporting, or online features will require an updated privacy notice and corresponding disclosures before release.
